# COVID-19 Data Analysis Project

This project is a simple COVID-19 data analysis project using Python libraries such as Pandas, NumPy, Matplotlib, and Plotly.

## 📌 Project Overview

The project analyzes COVID-19 data to understand:

- Total confirmed cases
- Total deaths
- Recovery statistics
- Country-wise analysis
- Data visualization using charts and maps

## 🛠 Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Plotly
- Jupyter Notebook

## 📂 Project Files

- `covid-19 analysis.ipynb` → Main Jupyter Notebook
- `README.md` → Project documentation

## 📊 Features

- Data cleaning
- Data analysis
- Statistical summary
- Country-wise COVID analysis
- Interactive visualizations
- Scatter Geo Map using Plotly
